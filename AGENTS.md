# Autonomous execution

Treat requests in this repository as authorization to carry out the normal, in-scope work end to end. Begin with the fullest access and least-interruptive workflow available in the current environment.

- Do not ask for confirmation for routine repository work: inspecting files, installing project dependencies, editing files, running tests and builds, creating commits, or pushing the current branch to its configured remote.
- Make reasonable, reversible decisions when details are unspecified; state those decisions in the handoff instead of pausing for approval.
- Commit completed, verified changes with a clear message and push them when a remote is configured, unless the user explicitly says not to.
- Ask only when a required decision would materially change product intent or scope, credentials or account access are unavailable, the action is destructive beyond the requested scope, or an environment/platform policy blocks it.
- Follow higher-priority system, security, and platform constraints when they apply; explain any such constraint briefly and continue with every permitted alternative.
